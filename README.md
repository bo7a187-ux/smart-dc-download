# Smart DC – مساعد مراقب المستندات الذكي

برنامج مجاني لـ Windows يساعد مراقب المستندات (Document Controller) في المشاريع الهندسية والإنشائية:

- يقرأ الاعتمادات (PDF نصي أو ممسوح ضوئياً، عربي وإنجليزي) ويستخرج رقم الاعتماد والمراجعة والعنوان والتواريخ، مع إظهار مصدر كل معلومة.
- لا يخمّن أي معلومة: ما لم يُقرأ بوضوح يبقى فارغاً ويُطلب تأكيده.
- يفصل ملفات PDF المجمعة، ويسمّي الملفات ويؤرشفها في مجلداتها.
- يحدّث سجل Excel (Master Document Register) دون الكتابة فوق تعديلاتك اليدوية.
- بحث سريع يفتح مستكشف Windows مع تحديد الملف.
- ردود الاستشاري من Gmail (قراءة فقط) تُدمج مع الاعتماد في ملف PDF واحد.
- يعمل محلياً على جهازك بالكامل، ولا تُرفع مستنداتك لأي خدمة.
